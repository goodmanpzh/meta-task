### Category: Software Engineering and System Design

Broad software engineering tasks covering system design, code architecture, interpreters/compilers, multi-language programming, and creative coding challenges.

**The examples below are for inspiration only. Be creative and design your own unique task!**

**Task Pattern Ideas**:
- Implement interpreters or emulators (CPU architectures, virtual machines, custom languages)
- Code golf challenges (implement complex functionality under strict size limits, e.g., <5KB)
- Polyglot programming (write code valid in multiple languages simultaneously, e.g., C and Python)
- Build system-level tools (terminal emulators, IPC mechanisms, process managers)
- Create domain-specific languages or parsers (grammar-based, stack-based, etc.)
- Implement protocol handlers (gRPC, WebSocket, custom binary protocols)
- Write metacircular evaluators or self-hosting compilers
- Create package managers or deployment automation tools (local PyPI server)
- Implement constraint-based solutions (regex-only algorithms, pure SQL computations)
- Async/concurrent task management with proper cancellation handling
- Legacy code modernization (COBOL to Python, Python 2 to 3)
- Headless terminal/PTY implementation

**Skills & Tools** (tag suggestions for your task):
- Core: `coding`, `software-engineering`, `system`
- Languages: `python`, `c`, `cpp`, `rust`, `assembly`, `cobol`, `scheme`
- Advanced: `interpreters`, `compilers`, `code-golf`, `polyglot`
- Tools: `terminal`, `async`, `concurrency`, `grpc`

**Possible Input Data** (be creative with environment files!):
- Source code for interpreters/emulators to implement
- Reference implementations (correct but slow/large)
- Language specifications (grammar files, semantics docs)
- Protocol definitions (gRPC .proto files, API specs)
- Binary files to interpret (ELF, bytecode, ROM images)
- Game ROMs or machine code to emulate
- Test suites for language conformance
- Performance benchmarks to beat
- Legacy COBOL code for modernization
- Scheme/Lisp code for metacircular evaluation
- Async task specifications (concurrent workloads)

**Verification Approaches**:
- Test against reference implementation
- Check code size limits (byte count, compressed size with gzip)
- Verify multi-language compatibility (compile/run with gcc AND python)
- Test interpreter/emulator correctness on sample programs
- Performance benchmarks (speed, memory usage)
- Byte-level output comparison

**Remember**: Software engineering tasks should test architectural thinking, system design skills, and creative problem-solving under constraints! Combine unusual requirements to create novel challenges.
