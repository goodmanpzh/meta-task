### Category: Algorithm Design and Implementation

Tasks requiring implementation of specific algorithms, data structures, or computational solutions with correctness and often performance requirements.

**The examples below are for inspiration only. Be creative and design your own unique task!**

**Task Pattern Ideas**:
- Implement mathematical/statistical algorithms (sampling methods, numerical optimization, matrix operations)
- Create domain-specific solvers (chess engines, scheduling, routing, constraint satisfaction)
- Build interpreters, parsers, or compilers for custom languages
- Implement compression/encoding algorithms
- Design efficient data structures with specific complexity guarantees
- Solve computational puzzles with constraints (logic gates, circuit design)
- Implement game AI or strategy optimization (CoreWars, board games)
- Probability distribution search and optimization
- Regex-based computation (implement complex logic using only regex)

**Skills & Tools** (tag suggestions for your task):
- Core: `coding`, `algorithms`, `optimization`, `mathematics`
- Domains: `data-structures`, `numerical-methods`, `constraint-satisfaction`
- Languages: `python`, `c`, `rust`, `R`, `assembly`
- Libraries: `numpy`, `scipy`, `sympy`

**Possible Input Data** (be creative with environment files!):
- Logic gate descriptions (text files defining circuits, truth tables)
- Chess/game positions (FEN notation, PGN files, board images)
- Formal grammars (BNF/EBNF definitions for parsers)
- Constraint specifications (SAT/SMT formulas, ICS calendar files, scheduling constraints)
- Reference implementations (slow but correct code to optimize)
- Mathematical functions or density functions (R/Python code)
- Domain-specific languages (Redcode, Brainfuck, custom interpreters)
- Matrix/vector data (NumPy arrays, sparse matrices)
- Graph structures (adjacency lists, GraphML files)
- Probability distributions (parameter specifications, sample data)

**Verification Approaches**:
- Test against known input/output pairs
- Statistical validation (mean, std deviation matching within tolerance)
- Performance benchmarks (speed comparison, complexity verification)
- Verify code size for code golf challenges
- Functional correctness on edge cases
- Output format and precision verification

**Remember**: These are just starting points. Design algorithmic challenges that test problem-solving creativity and mathematical reasoning!
