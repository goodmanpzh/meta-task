### Category: Web Development

Tasks involving web application development, API design, frontend/backend implementation across multiple languages and frameworks.

**The examples below are for inspiration only. Be creative and design your own unique task!**

**Task Pattern Ideas**:

*Python Web (Flask/FastAPI/Django):*
- Build REST APIs with specific endpoints and functionality
- Implement authentication/authorization systems (JWT, OAuth)
- Build database-backed APIs with SQLAlchemy (connection pooling, transactions, encoding)
- Create async API endpoints with proper error handling

*Java Web (Spring Boot/MyBatis):*
- Implement Spring Boot REST controllers with validation and exception handling
- Build MyBatis-Plus data access layers with optimized SQL queries
- Configure Spring Security authentication flows
- Implement transaction management with proper isolation levels

*Node.js (Express/Koa/NestJS):*
- Fix middleware ordering and async error handling bugs
- Implement route handlers with proper import paths after refactoring
- Debug race conditions in request processing
- Create WebSocket servers with connection management

*Ruby (Rails/Sinatra/ActiveRecord):*
- Fix ActiveRecord encoding and SQLite compatibility issues
- Debug Sidekiq background job processing (float precision, serialization)
- Implement Rails API endpoints with proper validations
- Fix database migration and schema issues

*General Web Tasks:*
- Create GraphQL APIs with specific schemas
- Implement rate limiting and API throttling
- Build webhook handlers and integrations
- Fix CORS, routing, and middleware bugs
- Implement caching layers (Redis, Memcached)
