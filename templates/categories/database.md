### Category: Database and SQL

Tasks involving database operations, SQL queries, schema design, query optimization, and database administration.

**The examples below are for inspiration only. Be creative and design your own unique task!**

**Task Pattern Ideas**:
- Write and optimize complex SQL queries
- Design database schemas for specific requirements
- Implement database migrations and schema evolution
- Query optimization (rewrite slow queries, add indexes)
- Implement stored procedures or triggers
- Database recovery and repair (corrupted files, backup restoration)
- Cross-database data migration (MySQL to PostgreSQL, etc.)
- Implement full-text search functionality
- Graph database queries (SPARQL, Cypher)
- Time-series data management and queries
- Implement database connection pooling
- Data integrity validation and cleanup
- Implement caching strategies with database backends

**Skills & Tools** (tag suggestions for your task):
- Core: `database`, `sql`, `data-management`, `query-optimization`
- Databases: `sqlite`, `postgresql`, `mysql`, `mongodb`, `redis`
- Languages: `sql`, `sparql`, `cypher`
- Tools: `sqlite3`, `psql`, `mysql-client`, `pgcli`

**Possible Input Data** (be creative with environment files!):
- SQLite database files (`.sqlite`, `.db`)
- SQL dump files (`.sql`) with schema and data
- Database backup files for restoration
- Slow query logs for optimization tasks
- Schema definition files (DDL scripts)
- CSV/JSON data for import tasks
- SPARQL endpoints or RDF data files (`.ttl`, `.rdf`)
- Query result expectations for verification
- Database configuration files
- Index statistics and query plans

**Verification Approaches**:
- Verify query results match expected output
- Check query performance (execution time, explain plan)
- Validate schema correctness (constraints, relationships)
- Test data integrity after migrations
- Verify index usage in query plans
- Check transaction handling (ACID compliance)
- Test concurrent access scenarios

**Remember**: These are just starting points. Create database challenges that test SQL proficiency, query optimization skills, and understanding of database internals!
